# Character Style Reference

This image is the visual target for **JEN Simulator** character design.

![JEN Simulator character style reference](./character-style-reference.jpg)

## Direction

Characters should follow this reference for:
- very cute chibi proportions
- large expressive heads and faces
- soft rounded silhouettes
- warm, clean, hand-drawn/cozy styling
- varied Vietnamese island visitors, workers, families, merchants, tourists, and residents
- expressive outfits and props that clearly communicate each character's role
- consistent proportions across NPCs, customers, employees, story characters, and the player

This is a **style reference**, not a sprite sheet to copy literally. New game characters should remain original while matching this level of charm, polish, readability, and visual consistency.
